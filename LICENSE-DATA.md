# Licencia de los datos

El **catálogo** (`catalogo/`), los **datasets curados** (`datasets/`) y el **banco de verdades** de
este repositorio se publican bajo
[Creative Commons Atribución-CompartirIgual 4.0 Internacional (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/deed.es).

Cada dato que Terranova entrega conserva **la licencia y la atribución de su fuente**, declaradas en
el campo `procedencia` de cada respuesta. Muchas fuentes colombianas (datos.gov.co y la base catastral
pública del IGAC, entre otras) son CC BY-SA 4.0: lo derivado de ellas se distribuye con la misma
licencia.

Terranova no impone restricciones adicionales sobre los datos que entrega.
