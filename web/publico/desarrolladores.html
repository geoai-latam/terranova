Inicio rápido

Dale esta instrucción a tu agente y se configura solo.

Conéctate al servidor MCP de Terrnova en https://terrnova.com/mcp/catalogo (transporte HTTP) con la cabecera «Authorization: Bearer» y mi llave, que está en la variable TERRNOVA_LLAVE. Úsalo para responder con datos oficiales de Colombia: predios, estadísticas, contratación pública, ambiente, justicia, empresas y normas. Cita la entidad y la licencia que vienen en «procedencia» y no confundas «no_encontrado» con un error de la fuente. Guía para agentes: https://terrnova.com/llms.txt

  1. Pide tu llave de prueba (300 créditos por 15 días). Guárdala como secreto, nunca en el código.
  2. Haz la primera consulta (1 crédito):
export TERRNOVA_LLAVE=rt_live_...
curl -s -X POST https://terrnova.com/v1/co/territorio/dane_divipola_buscar \
  -H "Authorization: Bearer $TERRNOVA_LLAVE" \
  -H "Content-Type: application/json" \
  -d '{"nombre":"Cali"}'

Trae "estado":"encontrado", los municipios en datos.elementos y la fuente (DANE) con su licencia en procedencia. Respeta las tildes: «Bogota» no encuentra «Bogotá».

  1. Mira tu saldo con GET /v1/uso.

Funciona con Claude Code, Cursor y Claude Desktop, con las configuraciones de abajo. claude.ai y ChatGPT en la web todavía no conectan: sus conectores piden OAuth y Terrnova usa una llave en la cabecera. El inicio de sesión con OAuth llegará; mientras tanto, usa Claude Desktop con mcp-remote o la API.

MCP

Streamable HTTP, con la llave en Authorization.

Claude Code:

claude mcp add --transport http terrnova https://terrnova.com/mcp \
  --header "Authorization: Bearer $TERRNOVA_LLAVE"

Cursor y clientes con url y headers:

{
  "mcpServers": {
    "terrnova": {
      "url": "https://terrnova.com/mcp/territorio",
      "headers": { "Authorization": "Bearer rt_live_..." }
    }
  }
}

Clientes solo stdio (Claude Desktop), con mcp-remote:

{
  "mcpServers": {
    "terrnova": {
      "command": "npx",
      "args": ["mcp-remote", "https://terrnova.com/mcp/ambiente",
               "--header", "Authorization:${TERRNOVA_AUTH}"],
      "env": { "TERRNOVA_AUTH": "Bearer rt_live_..." }
    }
  }
}

Perfiles

RutaQué exponePara
/mcpLas 205 herramientas, ficha_lugar, ficha_empresa y fuente_describirClientes que buscan herramientas solos, como Claude
/mcp/<familia>Las de una familiaUn solo tema: lo más preciso y rápido
/mcp/catalogoPocas herramientas que buscan en el catálogoClientes con tope de herramientas (OpenAI: 128)

Familias: ambiente, contratacion, empresas, estadisticas, justicia, normativa, territorio. Todos traen las de nombre a código (1 crédito) y fuente_describir (gratis).

API REST

POST /v1/co/<familia>/<herramienta> con la entrada en JSON; la ficha de un lugar, POST /v1/fichas. Esquema en /openapi.json y /docs.

ParaDónde
Lista de herramientas con su costoGET /v1/herramientas
Ficha técnica de una fuenteGET /v1/fuentes/{fuente_id}
Saldo del mesGET /v1/uso
Estado por fuenteGET /v1/estado

Las rutas de catálogo son públicas y gratis.

Contrato rt/1

Toda consulta devuelve el mismo sobre:

CampoContenido
estadoencontrado, no_encontrado, fuera_de_cobertura o parcial
datosEl resultado
huellasha256 de datos, para verificar que no cambió
procedenciaPor fuente: entidad, URL, norma (si la hay), licencia, atribución, servido_desde, consultado_en y completitud
avisosLo que debes saber: total desconocido, datos no recientes, copia vencida…
geo_resultLas geometrías, en EPSG:4326 (lon, lat)
creditosLo que costó esa consulta

«No encontrado» no es «no se pudo». Si la fuente no responde llega un error, nunca un sobre vacío; un dato viejo (servido_desde: obsoleto) siempre llega con aviso.

Llaves

PrefijoPara qué
rt_live_Producción: licencia abierta verificada y dato público reutilizable, con aviso.
rt_test_Evaluación: además, las fuentes con licencia por verificar, con aviso.

Si una llave se filtra, la revocamos y te damos otra con el mismo saldo.

Errores

En application/problem+json (RFC 9457), con un code estable y el solicitud_id para soporte.

HTTPcodeQué hacer
400parametro_invalidoCorregir la entrada; param dice cuál
401no_autenticadoFalta la llave o no es válida
402saldo_agotadoSe acabaron los créditos del mes; dice cuándo se renuevan
403sin_permiso, licencia_no_habilitadaLa llave no cubre esa familia o esa fuente
404no_existeLa herramienta o la fuente no existe; la ficha de fuente sugiere ids parecidos
429limite_tasaEspera lo que dice Retry-After
502fuente_no_disponible, fuente_respuesta_invalidaNo se pudo: la fuente oficial falló o respondió algo que no se puede leer; reintenta más tarde
504fuente_lentaNo se pudo: la fuente no respondió a tiempo
500error_internoFalla nuestra; escríbenos con el solicitud_id

Ráfaga de 20 consultas y 60 por minuto por llave. Reintenta con espera creciente.

Recursos

  • /llms.txt: el catálogo en texto para agentes.
  • /.well-known/mcp/server-card.json: la tarjeta del servidor MCP.
  • /estado: el estado de la puerta y de cada fuente según su canario diario.
  • Soporte: soporte@terrnova.com, de lunes a viernes de 8:00 a 18:00, hora de Colombia, sin festivos.
