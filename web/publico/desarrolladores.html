Inicio rápido

  1. Pide tu llave. El plan Gratis trae 1.500 créditos al mes. Guárdala como un secreto, nunca en el código.
  2. Haz la primera consulta. El código DIVIPOLA de un municipio por su nombre cuesta 1 crédito:
export TERRANOVA_LLAVE=rt_live_...
curl -s -X POST https://terrnova.com/v1/co/territorio/dane_divipola_buscar \
  -H "Authorization: Bearer $TERRANOVA_LLAVE" \
  -H "Content-Type: application/json" \
  -d '{"nombre":"Cali"}'

La respuesta trae "estado":"encontrado", los municipios que coinciden en datos.elementos y la fuente (DANE) con su licencia en procedencia. La búsqueda respeta las tildes: «Bogota» no encuentra «Bogotá».

  1. Mira tu saldo con GET /v1/uso.

MCP

La puerta habla MCP por streamable HTTP, con la llave en la cabecera Authorization.

Claude Code:

claude mcp add --transport http terranova https://terrnova.com/mcp \
  --header "Authorization: Bearer $TERRANOVA_LLAVE"

Cursor y otros clientes que aceptan url y headers:

{
  "mcpServers": {
    "terranova": {
      "url": "https://terrnova.com/mcp/territorio",
      "headers": { "Authorization": "Bearer rt_live_..." }
    }
  }
}

Claude Desktop y otros clientes que solo hablan por stdio, con el puente mcp-remote:

{
  "mcpServers": {
    "terranova": {
      "command": "npx",
      "args": ["mcp-remote", "https://terrnova.com/mcp/ambiente",
               "--header", "Authorization: Bearer ${TERRANOVA_LLAVE}"],
      "env": { "TERRANOVA_LLAVE": "rt_live_..." }
    }
  }
}

API REST

Las herramientas siguen el patrón POST /v1/co/<familia>/<herramienta>, con la entrada en JSON. La ficha de un lugar está en POST /v1/fichas. El esquema completo, con la entrada de cada herramienta, está en /openapi.json y se navega en /docs.

ParaDónde
Lista de herramientas con su costoGET /v1/herramientas
Ficha técnica de una fuenteGET /v1/fuentes/{fuente_id}
Saldo del mesGET /v1/uso
Estado por fuenteGET /v1/estado

Las rutas de catálogo son públicas y no gastan créditos.

Contrato rt/1

Toda consulta que llega a la fuente devuelve el mismo sobre:

CampoContenido
estadoencontrado, no_encontrado, fuera_de_cobertura o parcial
datosEl resultado
huellasha256 de datos, para verificar que no cambió
procedenciaPor fuente: entidad, URL, norma, licencia, atribución, servido_desde, consultado_en y completitud
avisosLo que debes saber: total desconocido, datos no recientes, copia vencida…
geo_resultLas geometrías, en EPSG:4326 salvo que pidas crs_salida: EPSG:9377
creditosLo que costó esa consulta

«No encontrado» no es «no se pudo». Cuando la fuente no responde llega un error, nunca un sobre vacío. Terranova nunca inventa un dato ni hace pasar uno viejo por actual: servido_desde: obsoleto siempre llega con aviso.

Errores

En application/problem+json (RFC 9457), con un code estable y el solicitud_id que debes darnos si escribes a soporte.

HTTPcodeQué hacer
400parametro_invalido, zona_demasiado_grandeCorregir la entrada; param dice cuál
401no_autenticadoFalta la llave o no es válida
402saldo_agotadoSe acabaron los créditos del mes; dice cuándo se renuevan
403sin_permiso, licencia_no_habilitadaLa llave no cubre esa familia o esa fuente
404no_existeLa herramienta o la fuente no existe; sugiere ids parecidos
429limite_tasaEspera lo que dice Retry-After
502fuente_no_disponibleNo se pudo: la fuente oficial falló; reintenta más tarde
504fuente_lentaNo se pudo: la fuente no respondió a tiempo
500error_internoFalla nuestra; escríbenos con el solicitud_id

Cada llave tiene una ráfaga de 20 consultas y repone 60 por minuto. Reintenta con espera creciente, nunca en bucle cerrado.

Recursos

  • /llms.txt: el catálogo en texto para agentes.
  • /.well-known/mcp/server-card.json: la tarjeta del servidor MCP.
  • /estado: el estado de la puerta y de cada fuente según su canario diario.
  • Soporte: soporte@terrnova.com, de lunes a viernes de 8:00 a 18:00, hora de Colombia.
